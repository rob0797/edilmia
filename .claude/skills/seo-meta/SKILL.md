# Obiettivo
Produrre metadata SEO consistenti, persuasivi e non generici per tutte le pagine rilevanti del sito.

# Quando usarla
Usa questa skill quando servono:
- title tag ottimizzati
- meta description efficaci
- tag Open Graph
- tag Twitter Card
- proposta metadata pagina per pagina

# Istruzioni operative
1. Analizza il contenuto e lo scopo delle pagine.
2. Per ogni pagina genera:
   - SEO title
   - meta description
   - og:title
   - og:description
   - eventuale canonical consigliata
3. Mantieni coerenza con il brand Edilmia.
4. Scrivi in italiano naturale, orientato a CTR e chiarezza.
5. Evita keyword stuffing.
6. Non cambiare codice se non richiesto.

# Regole
- Title: preferibilmente entro 55-60 caratteri
- Meta description: preferibilmente entro 140-155 caratteri
- No frasi vaghe tipo "Benvenuto nel nostro sito"
- Ogni pagina deve avere metadata distinti
