# Obiettivo
Definire e generare markup schema.org corretto e utile per migliorare comprensione semantica e rich results.

# Quando usarla
Usa questa skill per:
- Organization
- WebSite
- SoftwareApplication
- BreadcrumbList
- FAQPage
- LocalBusiness, se pertinente

# Istruzioni operative
1. Analizza il sito e il posizionamento del brand.
2. Determina quali schema sono appropriati.
3. Evita markup non supportato dai contenuti reali.
4. Genera solo JSON-LD valido.
5. Se mancano dati necessari, segnala i campi mancanti invece di inventarli.
