# Obiettivo
Rafforzare la struttura dei link interni per migliorare discoverability, distribuzione del valore interno e chiarezza tematica.

# Quando usarla
Usa questa skill quando vuoi:
- capire come collegare meglio le pagine
- migliorare anchor text
- evitare pagine isolate
- costruire cluster semantici

# Istruzioni operative
1. Analizza le pagine principali del sito.
2. Identifica:
   - pagine orfane
   - pagine con pochi link interni
   - anchor troppo deboli
   - opportunità di cluster SEO
3. Proponi linking contestuale reale, non forzato.
