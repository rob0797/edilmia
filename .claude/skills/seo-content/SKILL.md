# Obiettivo
Migliorare contenuti e struttura semantica delle pagine per keyword targeting, search intent e chiarezza.

# Quando usarla
Usa questa skill quando vuoi:
- migliorare testi esistenti
- definire heading structure
- aggiungere FAQ
- allineare una pagina all'intento di ricerca

# Istruzioni operative
Per ogni pagina:
1. Identifica keyword principale
2. Identifica keyword secondarie
3. Definisci search intent
4. Proponi struttura H1/H2/H3
5. Evidenzia contenuti mancanti
6. Proponi FAQ SEO solo se davvero sensate
